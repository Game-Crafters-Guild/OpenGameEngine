# blend-samples fixture licenses

These files are test fixtures fetched on demand by the `FetchBlendTestSamples`
CMake target (`Tests/cmake/FetchBlendSamples.cmake`) from their canonical
public sources. They are not part of the engine and are never redistributed
with it. This file travels with the fixtures to satisfy the attribution
conditions of the CC-BY / CC-BY-SA bundles.
