Arabic shaping test font

NotoSansArabic-Regular.ttf is a subset of notofonts/noto-fonts at ffebf8c1, hinted/ttf/NotoSansArabic, retaining Basic Latin and Arabic test characters with layout features. It supports the existing ArabicRTLProducesGlyphs test independently of system font installation. It is test data, not a runtime localization feature.
