# lantern_body_tangents.gltf: provenance and license

One primitive (`LanternPole_Body`: 926 vertices, 872 triangles) copied byte for byte from the
Lantern model of the [Khronos glTF Sample Assets](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/Lantern)
(the copy committed at `Tests/EditorHarness/rg2-gate1-content/Assets/Models/Lantern/Lantern.glb`):
its positions, normals, texture coordinates, authored tangents and indices, in one embedded
buffer. The material keeps only a normal texture, a one-byte placeholder image. The glTF import
tests use the authored tangents as the reference for the tangents the importer generates.

Lantern: Frank Galligan (model), sbtron / Microsoft (conversion), CC0 1.0.
