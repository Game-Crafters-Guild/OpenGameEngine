## The two helmets: single-file copies

The Khronos repository ships SciFiHelmet and FlightHelmet only as a `.gltf` with separate buffer and image files. A page loads one file per model, so the demo site hosts a `.glb` of each, made once with a plain embed: no Draco compression and no texture re-encoding.

- Source: KhronosGroup/glTF-Sample-Assets at commit `edc7c9e67c639d230715049ee31f9a96a6babbbe`, `Models/<name>/glTF/`.
- Tool: gltf-pipeline 4.1.0 with cesium 1.121.0 pinned beside it (gltf-pipeline's unpinned cesium dependency fails at the current release).
- Command: `node node_modules/gltf-pipeline/bin/gltf-pipeline.js -i <name>/<name>.gltf -o <name>.glb`.
- Check: every embedded image is byte-identical to its source file (SciFiHelmet 4 of 4, FlightHelmet 15 of 15).
- sha256: `f71028d380e560fc…` for SciFiHelmet.glb and `eca9a3846c363ebc…` for FlightHelmet.glb.
- FlightHelmet lists `KHR_materials_transmission` (its lenses), which the importer does not implement; the lenses draw as ordinary surfaces.

## Sample models not in the list

The model viewer lists the Khronos samples that are CC0 or CC BY 4.0 (credited on screen), ship as one `.glb`, and use no glTF extension beyond the importer's (`KHR_materials_emissive_strength`, `KHR_mesh_quantization`, `MSFT_lod`). The test fixtures that also qualify (the `Compare*`, `Texture*`, `Interpolation`, `Unicode` and `NodePerformance` scenes) are left out because they are tests, not showcases. Excluded, with the reason:

| Model | Reason |
|---|---|
| CesiumMan | CC BY 4.0 (© 2017 Cesium); held out until it draws upright: its skinned mesh draws lying on its side |
| MetalRoughSpheres | CC BY 4.0 (© 2017 Ed Mackey); held out until it draws one grid of spheres: it draws two interleaved sets today |
| ChronographWatch, GlamVelvetSofa, MosquitoInAmber, IridescenceLamp, CarConcept | CC BY 4.0, and they need material extensions the importer does not implement |
| BrainStem, Duck | not CC0 (Poser EULA, SCEA) |
| ToyCar, SheenChair, DragonAttenuation | CC0, but needs clearcoat, transmission, sheen, volume or texture transforms, which the importer does not implement |
| Sponza | no single-file `.glb` in the repository |

## Public redistribution

CC0 rows permit public redistribution. CC BY 4.0 rows permit it with the listed
credits, source and license links, and any modifications identified. Keep this
file with packaged examples. The two converted helmets are the only locally
hosted derivatives described above; their container conversion is recorded.

DamagedHelmet includes a noncommercial condition. The model viewer lists it for the
non-commercial demo page: the page fetches it from Khronos's sample-assets host at run
time, never commits or hosts it, and shows its two-line credit. Sponza's model has custom terms; its CC BY
metadata is not a license for the model. It is not redistributed: it is fetched at build time with its
license beside it (see [Other assets](#other-assets)).

The model license and metadata records were also checked at Khronos revision
`2bac6f8c57bf471df0d2a1e8a8ec023c7801dddf`. Most example URLs still use `main`;
that moving source must be rechecked when a downloaded model changes. The
converted helmets retain their separate recorded source revision above.
