# Scripting ABI Docs

This folder groups documentation related to the native ↔ managed Scripting ABI.

## Core Specs
- `../ScriptingABI.md` – Canonical Scripting ABI spec (C API surface, calling conventions, handles, error codes).

Callback IDs (`GE_CB_*`) are declared in `Engine/Include/Scripting/ScriptingABI.h`, which is the only place they are defined.
