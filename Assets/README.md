# Engine content

This folder is not a project. It holds engine-level content that the build stages next to the Editor and the Player: `SkeletonProfiles/` (the runtime humanoid profile), `Materials/` (built-in materials, surface shaders and the material-graph samples), `Graphs/` (a graph the material-graph compiler tests read), `Textures/` (the bloom lens dirt and the moon), `RenderPipelines/` (the default `ForwardPlus` pipeline and its variants) and the two `UI/UIDemoPanel` files. `Apps/Editor/CMakeLists.txt` copies all of them into the staged `Assets/` folder beside the executable, where they are mounted as the `editor` asset source; `Apps/Player/CMakeLists.txt` stages the profile, the textures and the pipelines the same way. `StageTestAssets` (`Tests/CMakeLists.txt`) mirrors the whole folder into the build directory for the test suites, and `FetchFbxTestFixtures` extracts its local-only FBX archive into `Models/FBXTest/`. Projects keep their own content in their own `Assets/` folder and never use the repository root as a project root.
