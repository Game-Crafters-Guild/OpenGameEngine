# Moon disc texture

`moon_full.png` is the full-moon disc the sky renderer phases (`SkyRenderer`, `kSkyMoonFullTextureRelativePath`): a 1024×1024 RGBA PNG, the disc 88.9 % of the width with a soft edge, transparent outside.

Source: NASA's Scientific Visualization Studio, "Moon Phase and Libration, 2023" (SVS 5048), frame `phase_full.1571.tif` (3240×3240), a full-moon render from Lunar Reconnaissance Orbiter data. NASA imagery is in the public domain; credit "NASA's Scientific Visualization Studio". Conversion: the black sky keyed to alpha with a radial soft edge, the disc cropped and resampled (Lanczos); no color change.
